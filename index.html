About Hydra

Hydra is a very fast network logon cracker which supports many protocols. It is designed to be used for security auditing and penetration testing purposes.

Usage Examples

# Basic SSH attack
hydra -l admin -P passlist.txt ssh://192.168.1.1

# HTTP-GET attack
hydra -l user -P passwords.txt 10.0.0.5 http-get /login.php

Supported Protocols

  • SSH: Secure Shell
  • FTP: File Transfer Protocol
  • HTTP-GET/POST: Web authentication
  • Telnet: Remote login
